Construindo Ideias com Código

Sou estudante do curso de Desenvolvimento de Sistemas no Instituto Federal de Brasília (IFB) e estou em plena jornada de transição e aprendizado na tecnologia. Meu objetivo aqui é colocar em prática, de forma construtiva, tudo o que venho estudando, focando em escrever códigos mais limpos, organizados e acessíveis a cada dia.

Este espaço reúne os projetos e exercícios que desenvolvi nesta primeira etapa do curso usando HTML5, CSS3 e JavaScript. Entre eles, você encontrará desde páginas estruturadas até testes de interface e experimentos interativos — incluindo o meu primeiro jogo em formato web, um projeto que realizei com o apoio da inteligência artificial para ver um sonho sair do papel e que agora estou refatorando para aplicar as boas práticas que aprendi nas aulas.

Sinta-se à vontade para explorar os códigos, acompanhar minha evolução no GitHub e trocar ideias sobre desenvolvimento!

Em Expansão

Abaixo estão os conceitos e ferramentas que venho estudando e aplicando nos meus projetos no IFB e nos meus testes práticos:

  • HTML5 Semântico: Estruturação limpa de páginas com foco em acessibilidade e boas práticas.
  • CSS3 & Layouts: Estilização, organização visual e conceitos de responsividade para diferentes telas.
  • Lógica de Programação & JavaScript: Construção de algoritmos e manipulação dinâmica de elementos na web.
  • Git & GitHub: Versionamento de código, controle de alterações e publicação de projetos via GitHub Pages.
  • Prototipação & Design: Leitura e transposição de layouts (do Figma para o código) e organização de ambientes de desenvolvimento.

Experimentos Práticos

Conheça alguns dos projetos que desenvolvi durante minha trajetória no IFB e em estudos autônomos, aplicando conceitos de HTML5, CSS3, JavaScript e prototipação:

Jogo de Turno Web

Protótipo de jogo RPG em formato web desenvolvido em HTML, CSS e JavaScript. Criado como um experimento prático com suporte de Inteligência Artificial e atualmente em processo de refatoração para aplicação de boas práticas de arquitetura de código.

Projeto Portfólio (Figma)

Projeto de portfólio planejado e estruturado inicialmente no Figma e codificado do zero utilizando HTML5 e CSS3 responsivo, focando em hierarquia visual e organização de componentes.

Sistema de Agendamento Interativo

Interface de formulário estruturada para captação e agendamento de informações, aplicando elementos nativos de entrada de dados, seletores e organização estrutural em HTML5.

Site Institucional

Projeto comercial em desenvolvimento para um salão de atendimento local. Desenvolvido para estruturar a presença digital do cliente, exibir serviços e facilitar o contato, aplicando conceitos de design responsivo e arquitetura web voltada para negócios reais.
